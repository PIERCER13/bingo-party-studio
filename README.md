# Piercer Bingo Party Studio

Globo sorteador (75/90 bolas) com narração por voz e gerador de cartelas imprimíveis (A4 / PDF)

## Funcionalidades

- **Abas / Modos**: Globo Sorteador, Gerador de Cartelas
- **Seções principais**: Painel de Bolas Sorteadas, Gerar Cartelas para Impressão / PDF
- **Ações disponíveis**: Globo Sorteador, Gerador de Cartelas, Sortear Bola, Iniciar Auto, Reiniciar Globo, Gerar Cartelas, Imprimir / Salvar PDF (A4)
- **Persistência automática**: salva alterações automaticamente no navegador (`localStorage`).
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).
- **Impressão / PDF**: layout otimizado em folha A4 via `@media print`.

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8128`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8128`.
